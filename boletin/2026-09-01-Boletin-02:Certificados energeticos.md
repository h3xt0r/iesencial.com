# Boletín 02 — Certificados energéticos

Los certificados energéticos son documentos que acreditan la eficiencia
energética de un inmueble. Su emisión es cada vez más relevante para la
operación de las empresas.

## ¿Cuándo se necesitan?

- Al vender o rentar un inmueble.
- Para acceder a financiamientos verdes.
- Como requisito en licitaciones de gobierno.

## Beneficios para la empresa

Las instalaciones con mejor eficiencia energética reducen costos operativos de
forma permanente.

| Concepto            | Antes | Después |
| ------------------- | ----- | ------- |
| Consumo mensual     | 100%  | 72%     |
| Costo anual estimado| $120K | $86K    |
